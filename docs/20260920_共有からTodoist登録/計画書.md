## 1. 目的と対象外

**目的**: Android の Amazon ショッピング アプリ（ほか、URL を共有できるアプリ）の「共有」から、Chrome 拡張と同じ形式（短い件名のリンク＋説明欄のブロック）で Todoist にタスクを登録する。

**対象外（今回）**

- Google Play での公開（D3）。ただし targetSdk は Play の要件（36 以上）を満たすテンプレート値にしておく。**2026-09-21 に D14 で「限定配布アカウントで配る／Play には当面出さない」と決めた**（配布そのものは I7 で行う）
- 拡張の右クリックメニュー・キーボードショートカット・ページの DOM の読み取り（Android には無い）
- 価格の自動取得（D6）
- 「すぐ追加」（1 タップ登録）。共有項目を 1 つにしたため（D5）。フォームの「追加」がその代わり
- OAuth（拡張と同じく API トークンを貼る）、オフライン時の再送、ウィジェット、Wear OS

**分かったこと（I3 で解析を確定するときの前提）**

- **URL は `EXTRA_TEXT` の最後にある**（Amazon アプリ・ヨドバシ アプリ）か、**`EXTRA_TEXT` が URL だけ**（Chrome）。→ 「`EXTRA_TEXT` の中の http(s) URL」を取り、残りを商品名にする。残りが空なら `EXTRA_SUBJECT` を使う（Chrome）。
- **Amazon アプリの `EXTRA_SUBJECT` は定型文**なので使わない。商品名は `EXTRA_TEXT` から取る。extras の `url` に短縮 URL だけが入っているが、ほかのアプリには無いので頼らない（`imgUrl` も使わない）。
- **「セール: 」は Amazon アプリが付ける定型文**と見られる（S2）→ **取り除く（D13）**。拡張の `stripPromo` は【…】と […] だけを除くので、Android 版で足す。
- **ヨドバシの「通販【全品無料配達】」は、拡張の `yodobashi.cleanPageTitle`（`\s*通販【[^】]*】\s*$` と先頭の `ヨドバシ.com - `）でそのまま除ける**（S4 は URL を除いた残りに、S5 は `EXTRA_SUBJECT` に当てる）。
- **短縮 URL は共有のたびに変わる**（同じ商品で 2〜3 種類）→ **重複の確認は転送先の ASIN で行い、短縮 URL では比べない**。
- ⚠️ **オフライン（機内モード）では、Amazon アプリは短縮 URL を作らずフル URL（`https://www.amazon.co.jp/dp/{ASIN}…`）を共有する**（2026-09-21・I5 の受け入れで実測。フォームに【ASIN】が入り、D8 の警告は出なかった）。短縮 URL は Amazon のサーバーが作るためと見られる。→ **機内モードの共有は D8 の経路に入らない**ので、D8 を実機で確かめるときは解決できない短縮 URL（`https://amzn.asia/d/00000000` など）を `adb` で送る。
- **`referrer` は当てにならない**（ヨドバシ アプリは null）→ サイトは URL のホストで判定する。
- Chrome は `clipData` にページのサムネイル画像の `content://` URI を付けてくる → **読まない**（テキストだけを使う）。Amazon アプリ・ヨドバシ アプリの `clipData` は `EXTRA_TEXT` と同じテキスト。

## 4. 画面の流れ

```
Amazon アプリ →「共有」→ 共有シートで「ショップクリップ」
  └ ShareActivity（背景は透明）＋ボトムシート
      1. 受け取ったテキストから URL と名前を取り出す
      2. 短縮 URL なら転送先をたどって商品 URL にする（「読み込み中」を表示）
      3. フォーム（既定の登録先・ラベル・優先度が入った状態）
         ・タスク名（n / 500 文字）  ・商品名の全文（表示のみ）  ・ASIN / 商品コード
         ・現在価格（空欄）  ・プロジェクト  ・セクション  ・優先度  ・ラベル  ・メモ（最後）
         ・同じ ASIN のタスクがあれば警告（それでも追加できる）
         ・短縮 URL を解決できなければ警告（D8）
      4. 「追加」
         成功 →「追加しました」「Todoist で開く」、3 秒で閉じて Amazon アプリへ戻る
         失敗 → メッセージを出して閉じない（もう一度押せる）
      ※ トークン未設定なら「設定を開く」だけを出す

ランチャーのアイコン → 設定画面（MainActivity）
  トークン（伏せ字）→「接続テスト」→ 既定のプロジェクト・セクション → サイト別ラベル・追加ラベル・優先度・短縮文字数 →「保存」
  末尾に「Todoist とは関係がない」旨の注記
```

- 空白: `collapse`・`trim` は JavaScript の `\s`（全角スペース・NBSP などを含む）に合わせた。Java の `\s` は ASCII だけなので、文字クラスを明示した。

- `clampInt`: `Number.parseInt` と同じく先頭の整数を読む（`"3.7kg"` → 3）。
- 設定の移行（`migrateSettings`）: 版・旧既定値の表・既定値を引数にし、Android 版の版 1 のうちから仕組みをテストできるようにした。
- 【取込元】の既定は `Androidアプリ（共有）`。`sites` の `sourceLabel` は §5 の文言。
- `SiteAdapter` に `shortUrlHosts`（Amazon＝`amzn.asia`）と `cleanSharedName`（共有テキストの名前を整える。既定は `cleanPageTitle`、Amazon は「セール: 」も除く＝D13）を足した。

## 7. モジュールとクラスの構成

モジュールは `app` の 1 つだけ（規約 §6.1）。パッケージ `jp.trackrail.shopclipper`:

```
core/            純粋な Kotlin（Android に依存しない・JVM 単体テストで網羅）
  Text.kt  TaskFormat.kt  ProjectOptions.kt  Settings.kt  Draft.kt
  sites/  SiteAdapter.kt  Amazon.kt  Yodobashi.kt  Sites.kt
share/           SharedTextParser.kt（URL と名前の取り出し）  ShortUrlResolver.kt（転送先をたどる）
todoist/         TodoistClient.kt  TodoistError.kt  Models.kt（kotlinx.serialization）
net/             HttpTransport.kt（interface・I3）  UrlConnectionTransport.kt（HttpURLConnection・I4）
data/            SettingsRepository.kt（DataStore）  TokenCipher.kt（interface）  KeystoreTokenCipher.kt
ui/share/        ShareActivity.kt  ShareViewModel.kt  ShareSheet.kt（@Composable）
ui/settings/     MainActivity.kt  SettingsViewModel.kt  SettingsScreen.kt（@Composable）
ui/theme/        テンプレートのまま
```

- **追加する依存**（Version Catalog・版はそのときの安定版を公式で確かめる）: kotlinx-serialization-json（＋コンパイラ プラグイン）、DataStore Preferences、lifecycle-viewmodel-compose、kotlinx-coroutines-test（テストのみ）。HTTP は `HttpURLConnection`（追加の依存なし）。
- **マニフェスト**: `INTERNET` 権限。`ShareActivity` は `exported=true`・`SEND`／`text/plain` の intent-filter・表示名「ショップクリップ」・透明テーマ・最近のアプリ一覧に出さない。
- **短縮 URL の解決**: 既知の短縮ホスト（I2 の実測では `amzn.asia` だけ＝§2）だけを対象にし、転送を自動で追わずに `Location` を最大 5 回たどる。行き先が Amazon のホストでなければ打ち切る（受け取ったテキストを信頼しない）。タイムアウト 10 秒。
- **トークン**: 端末の中だけ。Keystore の鍵で暗号化して DataStore へ。**DataStore をバックアップの対象から外す**（別の端末へ復元されても鍵が無く読めないため）。復号できないときは「未設定」として扱う。トークンと `Authorization` ヘッダーはログに出さない。
