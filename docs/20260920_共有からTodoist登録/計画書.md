## 1. 目的と対象外

**目的**: Android の Amazon ショッピング アプリ（ほか、URL を共有できるアプリ）の「共有」から、Chrome 拡張と同じ形式（短い件名のリンク＋説明欄のブロック）で Todoist にタスクを登録する。

**対象外（今回）**

- Google Play での公開（D3）。ただし targetSdk は Play の要件（36 以上）を満たすテンプレート値にしておく
- 拡張の右クリックメニュー・キーボードショートカット・ページの DOM の読み取り（Android には無い）
- 価格の自動取得（D6）
- 「すぐ追加」（1 タップ登録）。共有項目を 1 つにしたため（D5）。フォームの「追加」がその代わり
- OAuth（拡張と同じく API トークンを貼る）、オフライン時の再送、ウィジェット、Wear OS

## 4. 画面の流れ

```
Amazon アプリ →「共有」→ 共有シートで「ショップクリップ」
  └ ShareActivity（背景は透明）＋ボトムシート
      1. 受け取ったテキストから URL と名前を取り出す
      2. 短縮 URL なら転送先をたどって商品 URL にする（「読み込み中」を表示）
      3. フォーム（既定の登録先・ラベル・優先度が入った状態）
         ・タスク名（n / 500 文字）  ・商品名の全文（表示のみ）  ・ASIN / 商品コード
         ・現在価格（空欄）  ・プロジェクト  ・セクション  ・優先度  ・ラベル  ・メモ（最後）
         ・同じ ASIN のタスクがあれば警告（それでも追加できる）
         ・短縮 URL を解決できなければ警告（D8）
      4. 「追加」
         成功 →「追加しました」「Todoist で開く」、3 秒で閉じて Amazon アプリへ戻る
         失敗 → メッセージを出して閉じない（もう一度押せる）
      ※ トークン未設定なら「設定を開く」だけを出す

ランチャーのアイコン → 設定画面（MainActivity）
  トークン（伏せ字）→「接続テスト」→ 既定のプロジェクト・セクション → サイト別ラベル・追加ラベル・優先度・短縮文字数 →「保存」
  末尾に「Todoist とは関係がない」旨の注記
```

## 5. 登録の形式（拡張との差分）

| 項目 | 拡張 v2.0.0 | Android 版 |
|---|---|---|
| 件名 | `[商品名を 60 字に短縮](正規化した URL)`、500 字以内 | **同じ** |
| URL | `/dp/{ASIN}`・`/product/{18桁}/`、対応外は `?` 以降を除く | **同じ**（短縮 URL は転送先から ASIN を取る） |
| 【メモ】 | 選ぶ画面で書いたときだけ先頭に | **同じ** |
| 【商品名】 | ページの商品名の全文 | 共有テキストの商品名（定型文の除き方は実測で決める） |
| 【現在価格】 | 読めなければ「取得できず」 | **入力したときだけ出す**（D6） |
| 【ASIN】／【商品コード】 | あり | **同じ** |
| 【取込元】 | `Chrome拡張（Amazon商品ページ）` など | `Androidアプリ（Amazon共有）`／`Androidアプリ（ヨドバシ.com共有）`／対応外は `Androidアプリ（共有）` |
| ラベル・優先度・登録先 | 設定どおり（既定: ラベルなし・P4・インボックス） | **同じ** |
| 重複の確認 | すぐ追加は登録しない／選ぶ画面は警告 | 警告だけ（D5 で「すぐ追加」が無いため） |

説明欄の例（価格を入れなかった場合）:

```
**【商品名】**
（商品名の全文）

**【ASIN】**
B0XXXXXXXX

**【取込元】**
Androidアプリ（Amazon共有）
```

## 7. モジュールとクラスの構成

モジュールは `app` の 1 つだけ（規約 §6.1）。パッケージ `jp.trackrail.shopclipper`:

```
core/            純粋な Kotlin（Android に依存しない・JVM 単体テストで網羅）
  Text.kt  TaskFormat.kt  ProjectOptions.kt  Settings.kt  Draft.kt
  sites/  SiteAdapter.kt  Amazon.kt  Yodobashi.kt  Sites.kt
share/           SharedTextParser.kt（URL と名前の取り出し）  ShortUrlResolver.kt（転送先をたどる）
todoist/         TodoistClient.kt  TodoistError.kt  Models.kt（kotlinx.serialization）
net/             HttpTransport.kt（interface）  UrlConnectionTransport.kt（HttpURLConnection）
data/            SettingsRepository.kt（DataStore）  TokenCipher.kt（interface）  KeystoreTokenCipher.kt
ui/share/        ShareActivity.kt  ShareViewModel.kt  ShareSheet.kt（@Composable）
ui/settings/     MainActivity.kt  SettingsViewModel.kt  SettingsScreen.kt（@Composable）
ui/theme/        テンプレートのまま
```

- **追加する依存**（Version Catalog・版はそのときの安定版を公式で確かめる）: kotlinx-serialization-json（＋コンパイラ プラグイン）、DataStore Preferences、lifecycle-viewmodel-compose、kotlinx-coroutines-test（テストのみ）。HTTP は `HttpURLConnection`（追加の依存なし）。
- **マニフェスト**: `INTERNET` 権限。`ShareActivity` は `exported=true`・`SEND`／`text/plain` の intent-filter・表示名「ショップクリップ」・透明テーマ・最近のアプリ一覧に出さない。
- **短縮 URL の解決**: 既知の短縮ホスト（実測で決める。例 `amzn.asia`）だけを対象にし、転送を自動で追わずに `Location` を最大 5 回たどる。行き先が Amazon のホストでなければ打ち切る（受け取ったテキストを信頼しない）。タイムアウト 10 秒。
- **トークン**: 端末の中だけ。Keystore の鍵で暗号化して DataStore へ。**DataStore をバックアップの対象から外す**（別の端末へ復元されても鍵が無く読めないため）。復号できないときは「未設定」として扱う。トークンと `Authorization` ヘッダーはログに出さない。
